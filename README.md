# SubTrack – Digital Subscription Tracker

## Project Overview

SubTrack is a MySQL-based digital subscription management system that helps users manage subscriptions, track recurring expenses and monitor renewal dates.

## Features

- Add new subscriptions.
- View and filter subscription records.
- Update subscription details.
- Delete unwanted subscriptions.
- Track monthly and annual expenses.
- Monitor upcoming renewal dates.
- Categorize active and cancelled subscriptions.

## Technologies Used

- MySQL 8.0
- MySQL Workbench
- SQL

## SQL Concepts Covered

- CRUD operations
- Primary keys
- AUTO_INCREMENT
- Data types and constraints
- Aggregate functions
- Conditional statements
- Filtering and sorting
- Date functions

## Database Structure

- Database: `subtrack_db`
- Table: `subscriptions`

## How to Run

1. Install MySQL Server and MySQL Workbench.
2. Establish a local database connection.
3. Execute the SQL files in numerical order.
4. View the results in MySQL Workbench.

Execute the sample data insertion script only once on an empty table to avoid duplicate records.

## Conclusion

This project demonstrates practical knowledge of MySQL fundamentals, database management, CRUD operations and basic data analysis.
